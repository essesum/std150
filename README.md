# СТД 150 · Режиссёрская партитура

Закрытый рабочий сайт видеосценографии гала-концерта к 150-летию Союза театральных деятелей (Большой театр, 22.10.2026).

Сайт зашифрован: `index.html` содержит только шифротекст (AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций). Картинки и видео вшиты внутрь шифротекста, отдельных публичных файлов нет. Расшифровка происходит в браузере после ввода пароля.

## Обновить сайт
Исходник `inner.html` в репозиторий не кладётся (он открытый). Пересборка:

```bash
STD150_PASSWORD='новый-пароль' python3 build.py inner.html gate.html index.html
```

Смена пароля = пересборка с новым паролем и push. Старые сохранённые на устройствах ключи перестанут подходить автоматически.
